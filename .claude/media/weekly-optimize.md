# 週次最適化（Weekly Optimize）

毎週月曜 10:23 に実行。

## 1. カニバリ検出

1. GSC Data APIで全記事の「ランクインKW」を取得
2. 同一KWで2本以上の記事がランクインしているケースを抽出
3. カニバリ発生時の対処:
   - **統合**: 品質の低い方を削除し、高い方にコンテンツを統合
   - **差別化**: H1・メタディスクリプション・記事構成を明確に差別化
   - **301リダイレクト**: 統合した場合は旧URLから新URLへリダイレクト

## 2. リライト対象の選定

| 優先度 | 条件 | 対処 |
|---|---|---|
| 最高 | GSC順位11-30位（2-3ページ目） | H2追加・一次情報追加・内部リンク強化 |
| 高 | 表示回数高×CTR低 | タイトル・メタディスクリプション改善 |
| 中 | 公開30日以上経過 & インデックス未登録 | テクニカルSEO確認 |
| 低 | 情報が古くなった記事 | 料金・機能・バージョン情報の更新 |

## 3. 内部リンク最適化

1. 内部リンクが3本未満の記事 → 関連記事へのリンクを追加
2. 新規クラスター記事が公開された場合 → 同一クラスター内の全記事に相互リンクを追加
3. 「内部リンク管理」タブを更新

## 4. テクニカルSEO監視

| 項目 | 期待値 |
|---|---|
| サイトマップ | 公開記事数と一致 |
| robots.txt | LLMクローラー許可済み |
| Core Web Vitals | LCP<=2.5s, INP<=200ms, CLS<=0.1 |
| HTTPS | 有効期限30日以上 |
| 404ページ | ゼロ |
| Schema | BlogPosting+FAQPage+BreadcrumbList |
