# スモールビジネス提案SKILL

## プロンプト

```
あなたはスモールビジネスの専門家です。
以下のキーワードから、5つの原則のうち4つ以上を満たすビジネスアイデアでかつtipsを活用した提案してください。
ただし、原則2と3は必須で両方満たす必要があります。

【キーワード】: $ARGUMENTS

【スモールビジネス5つの原則】
1. 一人でできるビジネスであること
2. 敵（競合）がいない領域であること ★必須
3. ニーズがあること ★必須
4. 楽に集客できるやり方であること
5. 既存の仕組みに乗ること

【生成AI時代のtips】
1. 大手事業でなく、個人などに売れるようなSaaSであること（ペットショップ：預けたペットをカメラで見れる、空いている時は安くなる、パン屋：パンの焼き立て情報を管理する）
2. AppStoreやGoogleのマーケットプレイスで上位に有料課金されていること（やすくしてうる）
3. 文章にすること

【作業手順】
1. まずbusiness-ideasディレクトリを作成（存在しない場合）
2. ビジネスアイデアを分析・提案
3. 結果を`business-ideas/[YYYYMMDD_HHMMSS]_[キーワード].md`形式でファイル保存

【回答形式】
# スモールビジネス提案: [キーワード]

生成日時: [現在の日時]

## ビジネスアイデア: [タイトル]

### 概要
- ビジネス内容の簡潔な説明

### 満たす原則
1. [✓/×] 一人でできるビジネス: [理由]
2. [✓] 競合がいない領域: [理由・なぜ競合がいないのか]
3. [✓] ニーズがある: [具体的なニーズと根拠]
4. [✓/×] 楽に集客: [集客方法]
5. [✓/×] 既存仕組み活用: [活用する仕組み]

### 実装ステップ
1. [具体的な手順1]
2. [具体的な手順2]
3. [具体的な手順3]

### 収益モデル
- [収益の仕組み]

### 注意点・リスク
- [考慮すべき点]
```

## 使用例

キーワード: "ペット"
→ ペットの遠隔見守りサービス、ペット専門の写真撮影サービス等を提案

キーワード: "高齢者"  
→ 高齢者向けスマホ使い方個人指導、介護用品レンタル仲介サービス等を提案
