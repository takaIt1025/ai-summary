## 軸別詳細

### ① 需要トレンド（3点）
- Google Suggestで確認できた需要シグナル: `積みゲー管理アプリ` / `ゲーム管理アプリ iphone` / `積みゲー解消`
- 最も有望なサジェスト: `積みゲー管理アプリ`（直接的な需要表現）
- 懸念点: Suggestの絶対量が少ない。ただしニンダイ・発売イベントのたびに需要スパイクが発生する

### ② 競合の隙間（5点）
- 競合アプリ数: 18件（うち真の競合は1件のみ）
- 強敵（レビュー1万超）: **0アプリ**
- 発見した隙間: ゲムコレ（最も近い競合）レビューわずか15件。PlayNaviは「ゲーム発見SNS」特化で積みゲー管理は付随機能
- 放置されている競合: ゲームソフトログ(¥500/11件)、ゲームメモ(★3.8/20件)

### ③ 収益ポテンシャル（3点）
- 有料アプリの存在: あり（ゲームソフトログ ¥500 / 11件）
- サブスク系: あり（ゲムコレのプレミアム機能・登録150件超で必須、キログのサブスク）
- 推定収益モデル: フリーミアム（上限解放）が最適。AI機能を追加すればサブスクも成立

### ④ 個人開発フィージビリティ（4点）
- MVP想定工数: **6〜8週間**
- 技術的リスク: IGDB API（月10万req無料枠）の利用。ゲムコレが実装済みで実現可能性証明済み
- 必要な外部依存: IGDB or RAWG API のみ。バックエンド不要

### ⑤ 拡散・発見しやすさ（3点）
- インフルエンサー流入の可能性: ゲーム実況者・Discordコミュニティへの訴求が有効
- SNS拡散の素地: 「積みゲー〇本解消！」成果シェアカードUIで自然なX投稿を誘発できる
- ASO依存度: 「積みゲー」「ゲーム管理」の2KWで上位獲得が現実的（競合弱）

## マネタイズ戦略と収益シミュレーション

### 推奨モデル

| モデル | 根拠 | 推奨度 |
|---|---|---|
| **フリーミアム（登録上限解放 買い切り¥480）** | ゲムコレが同方式で実証済み。ツール系との相性◎ | ★★★★★ |
| フリーミアム（月額サブスク ¥480/月）| AI優先提案機能を追加すれば継続課金の正当性が生まれる | ★★★★ |
| 広告モデル | DAUが少ないと効果薄。個人開発では効率悪い | ★ |
| 有料アプリ（¥500〜） | 競合が無料揃いの中で発見されにくい | ★★ |

**最終推奨**: フリーミアム（登録上限解放）→ AI機能追加後にサブスクへ移行 / 初期価格: ¥480
理由: まず無料で広げてDAUを確保し、登録本数が増えたタイミングで自然に課金を促す。ゲムコレと同じ設計で検証済みのモデル。将来的にAI優先提案機能を月額サブスクの目玉にアップグレードできる。

## 個人開発者への「次の一手」（Conditional Go）

### 弱い軸①「需要トレンド」の改善案

**案A: コミュニティ需要検証（推奨・今すぐ）**
- Xで「積みゲー管理アプリ作ってます」と投稿して反応を測る
- ゲーム系Discordサーバーにプロトタイプを見せてフィードバック収集

**案B: ニンダイに照準を合わせる**
- 次回ニンダイ発表後は「また積みゲー増えた」投稿が急増するタイミング
- このタイミングにTestFlightベータ公開を合わせると自然な流入を獲得できる

### 弱い軸②「収益性」を高める条件

- **AI優先提案機能**をサブスクの目玉にする（「今週どれから始める？」Claude API連携）
- 買い切りIAPとサブスクの**2段階課金**で課金ハードルを下げる

### MVPに含めるべき機能（優先順）

1. **ゲームタイトル登録**（IGDB検索 + バーコードスキャン）
2. **ステータス管理**（積みゲー / プレイ中 / クリア済 / 欲しいの4区分）
3. **成果シェアカード**（「積みゲー〇本解消！」グラフィック生成 → Xシェア）← 拡散性を補う
