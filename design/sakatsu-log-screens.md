# サ活ログ MVP 画面設計

作成日: 2026-05-07
対象: iOS / Flutter

---

## 画面一覧（全9画面）

| # | 画面名 | 種別 | 役割 |
|---|---|---|---|
| S1 | スプラッシュ | 全画面 | 起動時のロゴ表示 → 自動遷移 |
| S2 | オンボーディング | 全画面 | 初回起動時のみ（3ステップ） |
| S3 | ホーム（記録一覧） | Tab①ルート | サ活記録カードの一覧 + 今月サマリー |
| S4 | 記録入力 | ボトムシート | 新規サ活記録の入力フォーム |
| S5 | 記録詳細 | Push | 特定記録の詳細表示・編集・削除 |
| S6 | シェアカード | モーダル | ビジュアルカードのプレビューとSNSシェア |
| S7 | カレンダー | Tab②ルート | 月間カレンダー + サマリー |
| S8 | 設定 | Tab③ルート | 通知設定・Pro購入・各種リンク |
| S9 | Pro購入 | モーダル | IAP ¥480の購入・復元 |

## 状態管理の概要

```
Global State（アプリ全体で共有）
├── List<SakatsuRecord>  サ活記録一覧
├── bool isPro           Pro購入フラグ
└── Settings             通知設定等

SakatsuRecord
├── String id
├── String facilityName  施設名
├── DateTime date        日時
├── int sets             セット数（1〜10）
├── double totonoidegree ととのい度（1.0〜5.0）
└── String? memo         メモ（任意）
```
