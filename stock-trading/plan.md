# 日本株 AI運用システム — 構想メモ

## 概要

生成AIを活用した日本株の運用支援システムを構築する。
まずはセミオート（AI分析 → 人間執行）から始め、段階的にフルオートへ移行する。

## 基本構成

```
J-Quants API（JPX公式・無料）で株価データ取得
    ↓
Claude API で銘柄スクリーニング・分析
    ↓
通知（メール or LINE Notify）
    ↓
【オプション】カブコム証券 kabuステーションAPI で自動発注
```

## 証券会社APIの現状

| 証券会社 | API | 備考 |
|---|---|---|
| カブコム証券 | kabuステーションAPI（REST） | 最も充実。無料で使える |
| マネックス証券 | TradeAPI | 対応あり |
| SBI・楽天 | 実質なし | 自動発注は不可 |

## アプローチ比較

| アプローチ | 実現性 | リスク |
|---|---|---|
| 証券会社の公式API + Claude判断 | 高い | 低い・合法 |
| ブラウザ自動化（Playwright等） | 技術的には可能 | 証券会社の利用規約違反になる可能性あり |
| 生成AIが分析 → 人間が執行 | 最も現実的 | 低い |

## フェーズ別実装計画

### Phase 1 — データ取得 & 通知（まず作る）
- J-Quants APIで日本株データ取得
- Claudeで条件スクリーニング（PER・出来高・移動平均など）
- メール or LINE Notifyで通知

### Phase 2 — セミオート
- 通知を受けて人間が判断・手動発注
- 判断ログを蓄積してモデル改善

### Phase 3 — フルオート（任意）
- カブコム証券口座 + kabuステーションAPIで自動発注
- リスク管理ルール（損切りライン・最大ポジション）の実装

## 使用技術候補

- **J-Quants API**: 日本株の株価・財務データ（JPX公式・無料プランあり）
- **Claude API**: 銘柄分析・シグナル判断
- **kabuステーションAPI**: カブコム証券の発注API（フルオート時）
- **LINE Notify / Gmail**: 通知
- **Python**: データ取得・処理スクリプト
