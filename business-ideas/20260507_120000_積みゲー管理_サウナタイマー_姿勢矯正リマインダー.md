## ビジネスアイデア①: 「積みゲー週次プランナーBot（Discord/LINE）」

### 概要
- ゲーマーのDiscordサーバーやLINEに常駐するAI Botサービス。積みゲーを登録するとAIが「今週プレイすべきゲーム」と「週次目標時間」を提案し、達成度をシェアカード化してコミュニティに投稿できる。個人ゲーマーではなく「ゲームコミュニティ（Discordサーバー管理者）」に売るB2C2B構造。

### 満たす原則
1. ✓ 一人でできるビジネス: Bot開発はAPIベース。OpenAI + Discord/LINE API で一人で構築・運用可能
2. ✓ 競合がいない領域: 積みゲー管理はiOSアプリ市場でも競合15件以下。Discord Botとして特化したサービスは存在しない
3. ✓ ニーズがある: Google Suggestで「積みゲー管理アプリ」「積みゲー解消」が確認済み。Xでは「ニンダイ」後に積みゲー増加のトレンドが毎回発生
4. ✓ 楽に集客: ゲーム実況者・Discord管理者への無料トライアル提供→コミュニティ内で口コミ拡散。X投稿「積みゲー○本解消！」カードが自然なバイラル素地
5. ✓ 既存仕組み活用: Discord Bot Marketplace / LINE公式アカウント の既存流通に乗る。IGDB APIでゲームデータは無料取得

### 実装ステップ
1. Discord Bot（Python + discord.py）でMVPを2週間で作成。コマンド `/tsumige add [ゲーム名]` で登録、AIが週次プラン返答
2. 5つの無料ゲームコミュニティに無料提供 → フィードバック収集
3. プレミアムプラン（月額¥300/サーバー）でAI高精度提案・シェアカード生成・進捗グラフを提供

### 収益モデル
- 無料: 積みゲー登録のみ（最大10件）
- サーバープレミアム ¥300/月: 無制限登録 + AIプラン生成 + シェアカード
- 個人プレミアム ¥200/月: 個人向けLINE版
- 目標: 300サーバー × ¥300 = 月¥90,000

### 注意点・リスク
- Discordの利用規約変更リスク（プラットフォーム依存）→ LINEと並行展開で分散
- ゲームイベント（ニンダイ）タイミングでの流入が季節依存 → コンテンツマーケで平準化

## ビジネスアイデア②: 「サウナ施設向け 混雑・ローテーション管理SaaS」

### 概要
- 個人経営のサウナ・銭湯向けに、サウナ室→水風呂→外気浴の回転状況をリアルタイム管理するSaaS。QRコードで入退室を記録し、スタッフと客の双方がスマホで混雑を確認できる。「サウナタイマー」需要をBtoCではなくBtoB（施設向け）に転換した逆張り戦略。

### 満たす原則
1. ✓ 一人でできるビジネス: WebアプリSaaS（Next.js + Supabase）で一人開発・運用可能。初期は自分でオンボーディングも対応
2. ✓ 競合がいない領域: サウナイキタイ（7,736件）は施設検索SNS。回転・混雑管理に特化したBtoB SaaSは存在しない。完全な空白地帯
3. ✓ ニーズがある: サウナブームで個人経営サウナが急増（2020〜2026年で施設数2倍超）。スタッフが口頭で「サウナあと何分？」と聞かれる課題は全施設共通
4. ✓ 楽に集客: サウナ施設のオーナーが集まるFacebook/X のサウナ事業者コミュニティに直接DM。サウナ業界の展示会（サウナフェス等）で名刺配り
5. ✓ 既存仕組み活用: QRコード（無料生成）+ Supabase（無料枠あり）+ Stripe（決済）で既存インフラをフル活用

### 実装ステップ
1. 1施設のサウナオーナーにヒアリング → ペインを確認後、Google Sheetsで手動MVP（2週間）
2. WebアプリのMVP開発（4週間）: QRスキャン入退室 + 管理ダッシュボード + 混雑ランプ表示
3. 初期3施設に無料提供 → 改善後、月額¥3,000〜¥5,000でサブスク化

### 収益モデル
- ベーシック ¥3,000/月: 混雑管理 + QR入退室
- スタンダード ¥5,000/月: 売上分析 + 顧客満足度アンケート連携
- 目標: 50施設 × ¥4,000 = 月¥200,000
- アップセル: 「常連客向けセルフチェックイン機能」¥1,000追加

### 注意点・リスク
- ハードウェア（タブレット）が施設に必要 → 「スタッフのスマホで代用可」の設計で参入障壁を下げる
- 施設ごとにサウナ構造が異なる → ルーム数をカスタム設定できる柔軟な設計が必須

## ビジネスアイデア③: 「テレワーカー向け 姿勢ウェルネス Slack Bot」

### 概要
- Slackに常駐するBotが1時間ごとに姿勢チェックを通知し、30秒でできるAI生成ストレッチを提案するサービス。「姿勢矯正リマインダー」の需要をBtoC（個人）ではなく法人の福利厚生として販売するSaaS。テレワーク普及で企業の健康管理費用に予算がついている今が参入好機。

### 満たす原則
1. ✓ 一人でできるビジネス: Slack App + OpenAI API で構築。法人営業もメール/DM中心で一人対応可能
2. ✓ 競合がいない領域: 姿勢矯正アプリの競合（my Symmetry等）はすべてiOS個人向け。Slack Bot × 法人福利厚生という切り口での競合はゼロ
3. ✓ ニーズがある: Google Suggestで「姿勢矯正アプリ」「テレワーク 姿勢矯正」を確認。テレワーク定着で腰痛・肩こりは企業の生産性課題として認識が広がっている
4. ✓ 楽に集客: テレワーク系メディア（テレ博等）へのプレスリリース。Slackの App Directory への掲載（SEO効果）。ProductHuntへの投稿でグローバル流入も狙える
5. ✓ 既存仕組み活用: Slack App Marketplace の審査を通過すれば、Slack公式の流通網に乗れる。Stripe Billing で月次請求を自動化

### 実装ステップ
1. Slackワークスペーム内で自分自身に向けてBotを作成しプロトタイプ検証（1週間）
2. 知人の小規模リモートワーク企業3社に無料トライアル提供 → 継続率と反応を測定（2週間）
3. Slack App Directory に申請。法人向け ¥500/名/月 でサブスク開始。10名以上は ¥400/名 の割引設定

### 収益モデル
- 個人プラン ¥300/月（Slack個人ワークスペース向け）
- 法人プラン ¥500/名/月（10名チームで¥5,000/月）
- 目標: 30社 × 平均20名 × ¥500 = 月¥300,000
- アップセル: 月次「チーム健康レポート」PDF生成オプション ¥1,000/月

### 注意点・リスク
- Slack App Directoryの審査に1〜2ヶ月かかる → 審査中はDMでの直販でリード獲得を継続
- 法人契約は意思決定が遅い → 無料トライアル30日間で「やめる理由をなくす」設計が重要

## キーワード横断アイデア（ボーナス）: 「ゲーマー健康管理 オールインワンBot」

### 概要
- 3つのキーワードを統合。長時間ゲームプレイヤー向けに「サウナ式インターバルタイマー（60分ゲーム→10分休憩）」「姿勢リマインダー」「積みゲー進捗管理」を一つのDiscord Botで提供。「ゲーマーの健康管理」という明確なターゲットで差別化。

### なぜ面白いか
- 3つの需要（積みゲー・姿勢・休憩管理）がすべてゲーマーの日常課題として重なっている
- 競合はゼロ（各機能の組み合わせSaaSは存在しない）
- 「サウナ的インターバル法でゲームが上手くなる」という切り口でXバズを狙える
- ¥500/月サブスクで、1,000ユーザー達成で月¥500,000
